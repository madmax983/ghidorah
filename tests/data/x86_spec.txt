# x86-64 decoder spec vectors (design Section 5, AC-061).
#
# Each vector decodes at address 0x1000 with the default options.
# Line format: bytes|mnem|operands|len|flow
#
# - bytes: the instruction bytes in hex, separated by spaces.
# - mnem: the canonical mnemonic. `(vector)` marks an opaque form.
# - operands: the operand texts of the printer, separated by `,`. `?` is an opaque operand.
# - len: the instruction length.
# - flow: seq, jmp, jcc, call, icall, ijmp, ret or trap.
#
# An error line has `!truncated`, `!invalid`, `!invalid_in_mode` or `!unsupported` in the
# mnem field and an empty flow field. Its len field holds `need_at_least` for `!truncated`,
# `len_consumed` for `!invalid` and `len` for the other two errors.
#
# Source: GNU objdump 2.42 (`objdump -D -b binary -m i386:x86-64 -M intel`) for the text
# of each valid vector, changed to the printer syntax. A tier-2 test compares each line
# with GNU objdump again. The opaque and error lines follow design Section 5.1.
